
# QuickMath 2.1 🧮

**Think fast. Learn faster.**

QuickMath is a lightweight, interactive arithmetic quiz application built with HTML, CSS and JavaScript. It helps learners practise essential mathematical operations through randomised questions, difficulty levels and instant feedback.

## 🚀 Live Demo

[Play QuickMath](https://YOUR-USERNAME.github.io/QuickMath-2.0/)

Replace `YOUR-USERNAME` with your actual GitHub username.

## ✨ Features

- Four arithmetic operations:
  - Addition (+)
  - Subtraction (-)
  - Multiplication (×)
  - Division (÷)
- Three difficulty levels: Easy, Medium and Hard.
- Mixed operations mode.
- Randomly generated questions.
- Instant answer validation.
- Score tracking.
- Consecutive correct-answer streak tracking.
- Accuracy percentage.
- Keyboard support using Enter.
- Responsive mobile-friendly interface.

## 📱 How to Use

1. Open the live application.
2. Select your preferred difficulty.
3. Choose an arithmetic operation or mixed mode.
4. Solve the displayed question.
5. Enter your answer.
6. Tap Check Answer.
7. Track your score, streak and accuracy.
8. Tap Next Question to continue.

## 🎯 Project Objective

The goal of QuickMath is to make arithmetic practice accessible, engaging and interactive, especially for learners using mobile devices.
